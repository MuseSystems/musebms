    Modules

    MsbmsBuildLib

    MsbmsBuildLib is a comprehensive Elixir build utilities library that provides automated build, test, documentation, and maintenance tasks for multi-component projects within the Muse Systems Business Management System ecosystem.

    MsbmsBuildLib.Types

    Type definitions for the MsbmsBuildLib module.

    Mix Tasks

    Cleans database artifacts for MSBMS components.

    mix msbms.db.docs

    Builds database documentation for MSBMS components.

    mix msbms.elixir.build

    Builds Elixir components and database migrations for MSBMS projects.

    Cleans various Elixir-related artifacts for MSBMS components.

    mix msbms.elixir.deps

    Manages Elixir application dependencies.

    mix msbms.elixir.docs

    Builds Elixir documentation for MSBMS components using ExDoc.

    mix msbms.elixir.scaffold

    Scaffolds a new Elixir component for MSBMS projects.

    mix msbms.elixir.test

    Runs various types of Elixir tests for MSBMS components.
